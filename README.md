# Disciple.Tools - Grid Install (Deprecated)

> **This plugin is deprecated and no longer maintained.** Installing the full Location Grid database is part of the Disciple.Tools theme as of version 1.31.0. Deactivate and delete this plugin.

The theme installs administrative levels 0–2 by default (about 50,000 records). To install the full Location Grid database (380,000+ records, including levels 3–5 where a country has them), go to **Mapping > Levels** in WP Admin and use **Full Location Grid Database Install**. This plugin never shipped an installer of its own, only a placeholder admin page.

Version 0.2.0 loads nothing, so it doesn't conflict with the theme.
